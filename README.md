📊 E-Commerce Order & Return Rate Analysis Dashboard
🔍 Project Overview

This project analyzes Q4 2024 e-commerce order and return data to identify key drivers of high return rates and provide actionable business recommendations to improve profitability and operational efficiency.

🎯 Business Problem

Despite strong order growth during the festive season, the business experienced a high return rate, impacting revenue and logistics costs. The goal was to understand:

Why returns are high

Which customer segments and channels drive returns

🛠 Tools & Technologies

Excel – Data cleaning, validation, and documentation

Power BI – Data modeling, DAX measures, dashboards

DAX – KPI calculations and segmentation analysis

📈 Key KPIs Analyzed

Total Orders

Total Revenue

Average Order Value (AOV)

Delivered Orders

Overall Return Rate

🔎 Analysis Performed

Weekly order volume trend analysis (festive impact)

Return rate segmentation by:

Customer Type

Order Source

Payment Method

Product Category

💡 Key Insights

New customers have significantly higher return rates

Cash on Delivery (COD) orders show the highest return risk

Instagram Shop drives the highest return rate among channels

Certain product categories disproportionately contribute to returns

✅ Recommendations

Improve new customer experience with better size guides and reviews

Reduce COD dependency by incentivizing prepaid orders

Focus quality improvements on high-return product categories
